# Surabhi Mishra | Personal Portfolio Website

A fully responsive personal portfolio website built with **HTML, CSS, and JavaScript** as part of a web development assignment.

**Live Website:** https://surabhimishra1310.github.io/portfolio/

## About

I'm Surabhi Mishra, a B.Tech Computer Science & Engineering student (specialization in Cloud Computing and Artificial Intelligence) at Shri Ramswaroop Memorial University. This portfolio showcases my education, skills, and projects.

## Sections

- **Home:** introduction with an animated typing effect
- **About Me:** short bio and quick facts
- **Education:** academic background
- **Skills:** animated skill bars (HTML, CSS, JavaScript, Python, Java, Git & GitHub)
- **Projects:** featured work with links to GitHub
- **Contact:** contact form with validation and social links

## Features

- Responsive layout for mobile, tablet, and desktop (CSS Flexbox, Grid, and media queries)
- Mobile hamburger menu
- Dark and light theme toggle (saved in the browser)
- Typing animation in the hero section
- Skill bars that animate on scroll
- Scroll reveal animations and active navigation highlighting
- Contact form with JavaScript validation
- Back-to-top button

## Technologies Used

| Technology | Purpose |
| --- | --- |
| HTML5 | Semantic page structure |
| CSS3 | Styling, layout, theming, responsiveness |
| JavaScript | Interactivity and form validation |
| GitHub Pages | Hosting and deployment |

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/surabhimishra1310/portfolio.git
   ```
2. Open the folder and double-click `index.html` in your browser.

No installation or build step is needed.
